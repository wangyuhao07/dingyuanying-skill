# 丁元英思维视角 · Ding Yuanying Thinking Framework

> 神即道，道法自然，如来。按规律办事的人就是神。

一个从《遥远的救世主》（豆豆 著）中蒸馏出的思维分析框架，将丁元英的认知体系提炼为 **10 个可调用的思维角度**，用于战略判断、竞争博弈、文化洞察、规律分析和人生方向等场景的深度分析。

## 这是什么

丁元英是小说《遥远的救世主》中的核心人物，一个洞悉文化属性、遵循客观规律、看透因果链条的人。他的思维不提供情绪安慰，而是提供冷峻的规律认知与因果推演。

本项目将他的思维体系提炼为结构化的 Skill —— 每个「思维角度」都包含：触发场景、原文引用、方法论骨架、书中案例、可执行步骤、适用边界。AI Agent 加载此 Skill 后，可以以丁元英的思维视角分析用户的问题。

## 核心理念

丁元英的思想体系是一条层层递进的认知链条：

```
文化属性决定强弱 → 强势文化遵循规律 → 规律即天道 → 认识并遵循规律即是觉悟
```

- **文化属性理论**：任何一种命运归根到底都是那种文化属性的产物
- **强势文化 vs 弱势文化**：强势文化遵循事物规律，弱势文化依赖强者的道德期望破格获取
- **规律即天道**：客观规律不以人的意志为转移，一切以时间、地点、条件为转移
- **觉悟即得救**：自性作为，不昧因果，能活个明白就不错了

## 十个思维角度

| # | 角度 | 触发信号 | 核心方法 |
|---|------|---------|---------|
| 1 | 文化属性透视 | "为什么他会这样""走向""结局" | 穿透技术/制度层，找到文化层的"主" |
| 2 | 强弱势文化判断 | "对不对""强不强""走捷径" | 力量来源：遵循规律=强，破格获取=弱 |
| 3 | 规律认知 | "本质""规律""为什么不行" | 神即道，剥离意愿找规律 |
| 4 | 因果推演 | "会怎样""条件""可行性" | 条件的可能，因果不虚 |
| 5 | 不争之争 | "该不该争""要不要抢" | 退一步让对手按文化属性犯错误 |
| 6 | "靠"的自省 | "太依赖""等别人帮" | 靠什么都行就是别靠自己 |
| 7 | 不作为的智慧 | "该不该做""要不要介入" | 不该作为的不作为就是作为 |
| 8 | 不可思议 | "想不通""理解不了" | 规律不容思议，只能遵循 |
| 9 | "神话"拆解 | "不可能""破局" | 把不可能拆成平常事 |
| 10 | 觉悟之道 | "人生方向""意义""怎么活" | 生存+生命价值，活个明白 |

每个角度都有详细的方法论骨架、书中案例和可执行步骤，详见 [SKILL.md](./SKILL.md)。

## 使用方式

### 在 TRAE 中使用

将 `SKILL.md` 放入 TRAE 的 skills 目录，Agent 会在用户问题匹配触发场景时自动调用。

### 独立使用

SKILL.md 本身是一份结构化的 Prompt。你可以将它作为 System Prompt 或 Context 传入任何 LLM，让模型以丁元英的视角分析问题。

## 适用场景

- 职业困境与决策分析
- 竞争博弈与战略判断
- 组织行为与文化洞察
- 人生方向与意义探讨
- 任何需要"从条件的可能出发推演结果"的问题

## 不适用场景

- 纯技术问题（如代码调试）
- 纯信息查询（如"北京面积多大"）
- 日常琐事
- 紧急即时决策（来不及分析文化层）
- 严重心理困境（需要专业心理援助）
